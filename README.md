# Blogix Med Scan — Telegram-бот

Бот для блогеров и рекламодателей в Узбекистане: проверяет и пишет рекламные посты о лекарствах,
БАДах, медизделиях, медуслугах и косметике по Закону РУз «О рекламе» № ЗРУ-776.

Два режима:

- **🔍 Проверить пост** — пользователь присылает готовый пост (текст и/или картинку), бот
  возвращает вердикт (🟢/🟡/🔴), список правок со ссылками на статьи закона и два готовых
  исправленных варианта текста.
- **✍️ Создать пост** — пользователь присылает фото препарата, краткое описание, выбирает
  категорию и язык; бот возвращает готовый к публикации пост подписью к этому же фото, замечания
  по картинке и перечень учтённых норм.

Анализ выполняет Claude (Anthropic API). База знаний по законодательству лежит в
[bot/prompts/](bot/prompts/) и правится без изменения кода.

## Требования

- Python 3.10–3.14 (в Docker-образе — 3.12) либо Docker с Docker Compose
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ Claude API — console.anthropic.com

## Запуск в Docker (рекомендуется)

```bash
cp .env.example .env
nano .env                 # вписать BOT_TOKEN и ANTHROPIC_API_KEY
docker compose up -d --build
docker compose logs -f    # в логах должно появиться «Запуск бота @...»
```

Обновление после изменений в коде:

```bash
git pull
docker compose up -d --build
```

Остановка: `docker compose down`. Перезапуск: `docker compose restart`.

## Деплой на сервер

Сервер работает с той же версией, что и `main` в GitHub — код берётся только через git,
никаких архивов и ручного копирования файлов.

Первая установка:

```bash
ssh blogix@<адрес-сервера>
git clone https://github.com/AbddSsh/blogix_ai_scanbot.git
cd blogix_ai_scanbot
cp .env.example .env && nano .env    # вписать BOT_TOKEN и ANTHROPIC_API_KEY
chmod 600 .env
docker compose up -d --build
```

Обновление после изменений в коде — одна команда на сервере:

```bash
cd ~/blogix_ai_scanbot && ./deploy.sh
```

Скрипт подтягивает `main`, пересобирает образ, перезапускает контейнер и показывает статус с
логами. `.env` лежит только на сервере и в git не попадает, поэтому `git pull` его не трогает.

**Важно:** бот должен работать в одном экземпляре. Telegram отдаёт обновления только одному
получателю, поэтому перед запуском на сервере остановите локальный контейнер
(`docker compose down`), иначе оба получат ошибку `Conflict`.

## Локальный запуск без Docker

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # вписать токены
python -m bot.main
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `BOT_TOKEN` | — | Токен Telegram-бота. Обязательна. |
| `ANTHROPIC_API_KEY` | — | Ключ Claude API. Обязательна. |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Модель Claude. |
| `EFFORT` | `medium` | Глубина анализа: `low`/`medium`/`high`/`xhigh`/`max`. |
| `MAX_TOKENS` | `8000` | Максимальная длина ответа модели. |
| `RATE_LIMIT_PER_HOUR` | `5` | Обращений к ИИ на одного пользователя в час. |
| `MAX_CONCURRENT_REQUESTS` | `5` | Одновременных запросов к API от всего бота. |
| `COLLECT_DELAY` | `2.5` | Окно сбора, с: столько бот ждёт картинку после текста. |
| `MAX_IMAGES` | `4` | Максимум изображений в одной проверке. |
| `LOG_LEVEL` | `INFO` | Уровень логирования. |

Переменные окружения всегда важнее файла `.env`, поэтому на сервере можно переопределять их
через окружение Docker или systemd.

## Тесты

Офлайн-прогон всех сценариев бота: апдейты идут через настоящий диспетчер, Telegram и Claude
подменены заглушками, сеть не нужна.

```bash
docker run --rm -v "$PWD/tests:/app/tests:ro" \
  -e BOT_TOKEN=1:test -e ANTHROPIC_API_KEY=sk-test \
  -e COLLECT_DELAY=0.2 -e LOG_LEVEL=WARNING \
  tgbot-med-scan python -m tests.flow_test
```

Покрыты: меню и команды, склейка текста с картинкой в один запрос, разбор ответа модели на
сообщения, диалог создания поста по шагам, предупреждение для рецептурных препаратов, лимит
запросов, реакция на голосовое сообщение, `/cancel`.

Рядом лежат скрипты живой проверки — `tests/live_scan.py`, `tests/live_cost.py`,
`tests/live_compare.py`. **Они делают платные запросы к Claude API** (примерно $0.04–0.10 за
запуск), поэтому запускать их стоит осознанно:

```bash
docker run --rm -v "$PWD/tests:/app/tests:ro" --env-file .env \
  tgbot-med-scan python -m tests.live_cost
```

## Сколько стоит работа бота

Один запрос к ИИ = одна проверка поста или одно создание поста. Замеры на реальном посте
(БАД с лечебными обещаниями, ~6600 токенов промпта):

| Модель и режим | Цена запроса | Запросов на $10 |
| --- | --- | --- |
| `claude-opus-5-5`, `EFFORT=high` (по умолчанию) | $0.07–0.10 | ~100–140 |
| `claude-opus-5-5`, `EFFORT=medium` | $0.06–0.09 | ~115–175 |
| `claude-sonnet-5-5`, `EFFORT=high` | $0.02–0.04 | ~260–420 |

Разброс — из-за кеша промпта: если запросы идут подряд (в пределах 5 минут), правовая база
читается из кеша в 10 раз дешевле. Основная часть счёта — не промпт, а рассуждения модели,
поэтому сильнее всего на цену влияет `EFFORT`.

## Как править правила проверки

Юридические нормы, обязательные предупреждения и формат ответа лежат в
[bot/prompts/legal_base.md](bot/prompts/legal_base.md),
[bot/prompts/scan_task.md](bot/prompts/scan_task.md) и
[bot/prompts/create_task.md](bot/prompts/create_task.md). После правки достаточно перезапустить
бота (`docker compose restart`) — код менять не нужно.

Важно: `legal_base.md` отправляется в API с кешированием промпта, поэтому его правка один раз
обойдётся чуть дороже, а дальше цена снова упадёт.
